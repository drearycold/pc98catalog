－概要＆感想－
　ロリータ３部作の最後を締めくくる作品。ラストに相応しく女の子は可愛いし難易度も高い。
　前作でＲＡＰＥ魔の主人公にやられまくった少女達が反攻作戦に転じ、街のあちこちにトラップを仕掛けてきた。目的は前作の【ロリータ２～下校チェイス～】で名前だけが出てきた八重垣静香を倒す事。今回の女の子はかなり強く、事前にパワーアップしておかないと返り討ちにあってしまう。スカートの中からミサイルを打ってくる女の子もいるし…。

－攻略指針－
　歩くだけでも体力を消費するのでまずはオートバイとガソリンを拾う。女の子とＨするとパラメーターが激減するので、ゲームクリアを目指すときは女の子とＨしない。

－詳細攻略－
－－－　Ｌｏｌｉｔａ２’－－－
・食料を拾う
・オートバイを拾う（これで歩いても体力を消費しない）
・ガソリンを拾う
・鉄パイプを拾う
・バイブレーターを拾う
・ランドセルは「拾わない」
・パンティーを拾う
・使用済コンドームは「拾わない」
・ロープを拾う
・女の子と戦う
・酒は「拾わない」
・女の子と戦う
・食料を拾う
・薬を拾う
・薬を拾う
・食料を拾う
・ハンマーとナイフを拾う
・女の子と戦う
・食料を拾う
・パンティーを拾う
・トラックを拾う
・バリアを突き破って校内へ…

－－－　裏技　（　ＰＣ-８８ディスク版のみ確認　）－－－
【　ＣＧを見る　】
テストパターン時にＳＴＯＰキーを押して停止
RUN "GPCONT" 【 RETURN 】

※　私は　Ｎｏ.３５　が大のお気に入り^^;

【　パラメーターを増やす　】
テストパターン時にＳＴＯＰキーを押して停止
List 410【 RETURN 】
TEQ = 100 を 300 あたりに変更してリターン
RUN 【 RETURN 】
※　パワーは２００（入力は９９）、アームレベルとディフェンスは１００（入力は９９）が最大値なので、調子に乗って 900 とかにすると TEQ = 600 とかになって後でプログラムが落ちるので注意！

【　モザイクを外す　】
テストパターン時にＳＴＯＰキーを押して停止
画面が狭くて入力しずらいので
Console 0,25,0,1【 RETURN 】
Width 80,25【 RETURN 】
で画面モードを変更する

　テクノポリス８７年２月号に記載されているプログラムを打ち込んで実行するとモザイクが外れたＣＧが表示される
